# Краткая сводка по текущему устройству

Ниже только те выводы, которые удалось уверенно вытащить из `Паспорт.pdf` и `Руководство.pdf`.

## Что удалось понять

Текущее устройство представляет собой проводное средство связи типа абонентских аппаратов, работающих между собой по двухпроводной линии.

По смыслу документации читаются следующие признаки:

- связь громкоговорящая
- режим работы полудуплексный
- используются два взаимозаменяемых переносных абонентских аппарата
- аппараты соединяются двухпроводной линией связи
- питание автономное, от батарейных элементов
- есть вызов, голосовая передача и прием
- устройство ориентировано на тяжелые условия эксплуатации
- в документах есть признаки требований по искробезопасности / взрывозащите

## Что это означает для новой версии

Это хороший старт, потому что у заказчика уже есть:

- логика работы изделия
- понятный пользовательский сценарий
- готовая конструктивная база исходного устройства
- КД, на которую можно опираться при проектировании новой версии

Но переход на оптоволокно потребует новой проработки по следующим направлениям:

- формирование и прием сигнала в оптическом тракте
- интерфейс между голосовой частью и оптическим каналом
- питание на обеих сторонах линии, потому что по оптоволокну питание не передается
- новая схемотехника оконечного узла
- подтверждение требований по безопасности среды эксплуатации

## Что пока нельзя утверждать без КД

Без полного комплекта КД и схемы нельзя корректно ответить на следующие вопросы:

- можно ли сохранить большую часть существующей аналоговой части
- насколько целесообразно оставлять полудуплекс
- какой именно уровень защиты и сертификации нужен в новой версии
- какие узлы лучше адаптировать, а какие дешевле и надежнее спроектировать заново
