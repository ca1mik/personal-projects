# Предлагаемая архитектура системы

## Базовая структура

```text
[Абонентский блок A]
  микрофон / громкоговоритель
  кнопка вызова / управление
  аудиотракт
  контроллер / логика
  оптический модуль
  локальное питание
          |
          |   одномодовое оптоволокно 7-10 км
          |
[Абонентский блок B]
  микрофон / громкоговоритель
  кнопка вызова / управление
  аудиотракт
  контроллер / логика
  оптический модуль
  локальное питание
```

## Уровни архитектуры

### 1. Пользовательский уровень

- трубка / микрофон / громкоговоритель
- вызов
- индикация состояния
- режим разговора

### 2. Логический уровень

- управление режимами связи
- обработка вызова
- переключение состояний прием / передача
- контроль питания
- индикация ошибок

### 3. Транспортный уровень

- преобразование электрического сигнала в оптический
- передача по оптоволокну
- прием и обратное преобразование

### 4. Энергетический уровень

- локальное питание каждого блока
- защита по питанию
- контроль разряда
- при необходимости безопасное питание для опасной среды

## Что можно заложить сразу

Даже если на первом этапе нужен только аналог старой связи, архитектуру лучше сразу делать с запасом под:

- диагностику линии
- расширенную индикацию состояния
- запись служебных событий
- будущий переход на полный дуплекс
- работу через внешний пульт или базовый блок

## Рекомендуемая реализация первого этапа

Для первого рабочего прототипа я бы рекомендовал:

- два оконечных блока
- точка-точка
- одномодовое волокно
- полудуплексная логика
- локальное питание с обеих сторон
- отдельный анализ взрывозащиты до начала схемотехнической детализации
