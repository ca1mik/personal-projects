# Что можно отдавать заказчику прямо сейчас

## Можно отдавать

- `07_block_diagram.svg`
- `08_principle_scheme_draft.md`
- `13_reference_schematic_v1.md`
- `14_signal_and_net_matrix.csv`
- `15_preliminary_bom.csv`

## Как это позиционировать

Правильная формулировка:

"Подготовлен подробный reference schematic package для первой версии оптоволоконного аналога. На его основе можно запускать схемотехническую проработку и перенос в EDA, но перед выпуском в производство нужно подтвердить исходную КД, питание, среду эксплуатации и требования по безопасности."

## Чего не обещать

Не стоит писать заказчику, что:

- схема уже готова к производству
- по ней можно без дополнительных уточнений выпускать серию
- взрывозащита и сертификация уже закрыты

## Честный статус

Стадия документа сейчас:

- инженерный концепт: да
- pre-design / reference schematic: да
- рабочая EDA-схема: нет
- производственная КД: нет

## Что нужно от заказчика, чтобы перейти к следующей стадии

1. Исходная электрическая схема текущего устройства
2. Полный комплект КД
3. Точный формат питания
4. Требования по автономности
5. Подтверждение, нужна ли опасная сертифицированная среда
6. Требования к разъёмам, кабелю и условиям эксплуатации
