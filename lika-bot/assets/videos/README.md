# Видео для подарка

Папки считываются автоматически. Бот берёт название верхнего каталога как категорию:

- `random/` - случайные сюрпризы
- `family/` - видео от семьи
- `friends/` - видео от друзей
- `sister/` - видео от сестры
- `from_me/` - видео от тебя
- `special/` - особенный сюрприз
- `final/` - финальное видео дня

Поддерживаются файлы:

- `.mp4`
- `.mov`
- `.m4v`
- `.avi`
- `.mkv`
- `.webm`
- `.ogg` (голосовые)

После добавления новых файлов можно:

- подождать авто-сканирование по расписанию;
- выполнить админ-команду `/sync`.
