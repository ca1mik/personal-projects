# Assets

Сюда складывается весь рабочий медиаматериал.

## Правило хранения

- однотипные материалы держать в своих папках
- слабые дубли не оставлять в готовых папках
- исходники и финальные ролики не смешивать
- зажившие фото хранить отдельно от свежих работ

## Именование

Удобный шаблон имени файла:

`YYYY-MM-DD_client_service_zone_stage`

Пример:

`2026-06-06_anna_lettering_clavicle_final.jpg`
