# VK Brand Assets

Эта папка собрана как готовый комплект для оформления группы VK.

## Что внутри

- `cover.svg` — основная обложка сообщества
- `avatar.svg` — аватар
- `menu-*.svg` — карточки для меню, постов, виджетов и внутренних ссылок
- `album-*.svg` — обложки альбомов

## Как использовать

1. Открой нужный `.svg` в браузере, Figma, Illustrator или Inkscape.
2. Если нужно, поправь:
   - название бренда
   - город
   - формулировки
   - ссылки / CTA
3. Экспортируй в актуальный размер под VK.
4. Загрузи в группу.

## Важно

- Макеты сделаны в векторе, чтобы не привязываться к меняющимся размерам платформы.
- Если используете тезис про медицинское образование, он должен подтверждаться фактами.
- Финальные реальные фото работ лучше всего подставлять поверх этих макетов как отдельные экспорт-версии.
