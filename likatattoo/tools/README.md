# Рабочие файлы

Эти таблицы нужны не для отчетности ради отчетности, а чтобы не терять заявки, контент и отзывы по пути.

## Как использовать

- `client-pipeline.csv` - веди каждую новую заявку отдельной строкой.
- `outreach-contacts.csv` - отдельный слой для статусов рассылки и next step по контактам.
- `outreach-log.csv` - журнал всех действий по рассылке и обработке ответов.
- `outreach-templates.md` - живые тексты, follow-up и правила эскалации.
- `outreach-analysis-2026-06-01.md` - текущие выводы по качеству базы и стратегии.
- `content-planner.csv` - планируй посты, ролики и сторис.
- `review-tracker.csv` - отмечай, у кого уже запросили отзыв и зажившее фото.
- `monthly-kpi.csv` - заполняй итоги месяца.
- `check_public_domains.ps1` - быстро проверить DNS, HTTP и HTTPS по публичным доменам.

## Минимальная дисциплина

- обновлять `client-pipeline.csv` каждый день
- обновлять `outreach-contacts.csv` и `outreach-log.csv` после каждого касания
- обновлять `content-planner.csv` после каждого съемочного дня
- обновлять `review-tracker.csv` после каждого запроса отзыва
- обновлять `monthly-kpi.csv` в конце недели и месяца
