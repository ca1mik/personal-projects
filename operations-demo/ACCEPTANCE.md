## Дополнения по поручению владельца

- Пять ролей, админка пользователей, отключение доступа, сброс пароля, серверная проверка прав, CSRF и журнал действий.
- Отчёты с группировкой по сотруднику / партии / дате и рабочие панели сотрудников. В XLSX рассчитанная сводка, а не объект Excel PivotTable.
- Поручения из записи или партии: ответственный, срок, статусы, комментарии и журнал. Работник передаёт результат на проверку, руководитель завершает с комментарием.
- Объяснение изменения показателей: пересчёт до/после по тем же правилам, включая дубли и связанные партии. До 20 значимых событий из последних 100 правок.
- Закрытие модалок снаружи, Escape и крестиком; защита несохранённых правок. Версии файлов интерфейса обновляются при выпуске.

## Фактические проверки

**19 тестов прошли**: импорт/откат, работа без файлов, сохранение, расчёты, права/CSRF, журнал/восстановление, отчёты, цикл задачи, комментарии, ограничения сотрудника и объяснения изменений. Единственный warning относится к будущему изменению зависимости тестового клиента.

В браузере пройден цикл admin → production → director: создание из P-003, перевод в работу, исправление факта, передача на проверку, объяснение влияния и завершение с результатом. У работника видны только его участок, отчёты и задачи, без управления пользователями. Путеводитель открывает замечания без изменения записей.

После проверки исходный факт **1200** восстановлен через API для повторяемого показа. Учебное поручение открыто заново, причина возврата записана в комментарии. История реальных проверок сохранена. Внешняя копия имеет собственную базу и доступы; её изменения не переносятся из локальной базы при обновлении кода.

## Границы реализации

Нет интеграций с ERP / 1С / Битрикс24, произвольного конструктора ролей, SSO/MFA и производственной инфраструктуры. Порог факта больше трёх планов — явное допущение. Внешняя ссылка временная: нужны включённый компьютер, сервер и туннель. Полные правила расчётов и резервного копирования — в README.md.
