# Рубрики и будущий канал

## Работает сейчас

Heartbeat готовит до четырёх отдельных редакционных постов. Явные разделители `<!-- feed-post:news -->`, `memes`, `ideas`, `facts`, `mail` обрабатываются только внутри ответа автоматизации telegram. Первый пост сразу; следующие минимум через 300 секунд после фактической доставки предыдущей рубрики. Ответы на прямые команды не задерживаются. Очередь SQLite сохраняется при перезапуске. Ограничение: длительный простой может сдвинуть очередь; точное время выхода не гарантируется.

Короткая новость с одной доступной локальной фотографией отправляется фотографией с подписью, без отдельного дубликата текста. Кредит из alt изображения включается в подпись. Длинный текст уходит отдельно от фото. Между текстом и медиа одного поста паузы нет. Новостные URL скрываются прежним транспортом; ссылки на TikTok/Shorts в рубрике memes сохраняются. Хештег рубрики добавляется при отсутствии.

Проверки: 172 теста прошли 24.10.2026; четыре новых сценария проверяют разбиение, интервалы, отсутствие дублей, фото-подпись и независимость обычного ответа. Это проверка очереди, не подтверждение будущих публикаций в ещё не подключённом канале.

## Подключение канала после адреса от владельца

1. Владелец добавляет существующего бота администратором с правом публикации сообщений. Управление администраторами ему не нужно.
2. Проверить реальный chat id, название, полномочия бота через Telegram API. Явно сохранить этот канал отдельно от owner_chat; управление ПК и личную почту в канал не маршрутизировать.
3. Первый тестовый пост, проверка результата. Затем отдельная редакционная очередь канала: рубрика, источник, медиа, время, состояние публикации, Telegram message id, защита от повторов.
4. До подключения канал не используется. Сейчас посты направляются только владельцу.

## Видео: отправка реализована 25.10.2026; монтаж остаётся следующим этапом

- Локальные MP4/M4V с заголовком ftyp и размером до 49 МБ идут через sendVideo с supports_streaming, подписью и кнопками оценки. Для выбранных файлов дополнительно проверены реальные дорожки через ffprobe. Короткий одиночный редакционный видеопост отправляется одним видео с подписью; несколько видео прямого ответа используют отдельные alt-подписи без стены локальных ссылок. Получение файла с платформы и получение сообщения в Telegram проверяются отдельно.
- Для собственных роликов владельца или материалов с разрешением: FFmpeg, вертикальный холст 1080×1920 без растяжения, обрезка, нормализация громкости, субтитры из локального распознавания, короткая заставка рубрики и указание автора.
- Сначала локальный файл и просмотр результата. Не удалять авторские водяные знаки, не приписывать чужое авторство. У репостов сохранять автора и оригинал.
- Для новостей не превращать монтаж в выдуманное свидетельство события: реальные кадры, даты, понятные архивные пометки.
- Распознавание речи загруженного файла может дать текст, но не означает, что текущий браузерный инструмент слышит системный звук. Просмотр кадров и слышание аудио — разные возможности.

## Наблюдения по ленте

Сохранять только наблюдавшиеся кадры/подписи, автора, установленную дату и реальный URL. Не присваивать пользовательский лайк без оценки владельца. Не называть локальный журнал обучением весов модели. Между запусками постоянный просмотр не ведётся.
