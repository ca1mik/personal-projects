Навыки находятся в `.codex/skills` текущего пользователя и станут доступны агенту со следующего сообщения. `hf-cli` и `hf-mem` дополнены локальными путями Windows. Установка навыков сама по себе не меняет веса модели Codex и не заменяет распознавание речи бота.

Hugging Face CLI 2.3.0 уже установлен в `.venv/Scripts/hf.exe` этого проекта. `hf-mem` 0.5.6 установлен отдельно в `.tools/hf-mem-venv`, чтобы его зависимости не изменяли работающий бот. Дополнительная облачная авторизация для проведённых публичных запросов не требовалась. Облачные задания, публикации и загрузки личных файлов не выполнялись.

Проверенное оборудование: AMD Ryzen 7 5700X3D, 32 ГБ системной памяти, NVIDIA RTX 5070 Ti с примерно 16 ГБ VRAM; CTranslate2 видит одну CUDA-видеокарту. Само выполнение Whisper на GPU в рамках этой установки не тестировалось.

Для следующего улучшения распознавания речи подобраны [Whisper large-v3-turbo](https://huggingface.co/openai/whisper-large-v3-turbo) и его [конверсия для faster-whisper](https://huggingface.co/dropbox-dash/faster-whisper-large-v3-turbo). Сейчас бот по-прежнему использует Whisper Base на CPU. Весовые файлы новых моделей не загружались; переключение не выполнялось. Перед переключением стоит сравнить качество и задержку на нескольких разрешённых голосовых сообщениях и проверить библиотеки CUDA/cuDNN. Одного обнаружения GPU для подтверждения совместимости недостаточно.
