# Автозапуск, управление ПК и личные настройки

Настроено 24 октября 2026 года. Все команды доступны только привязанному владельцу в личном чате бота.

## Включение компьютера

После **входа пользователя в Windows** задача `PersonalWindowsAgent` запускает `startup_chain.py`. Скрипт запускает установленный Happ 4.3 по пути `C:\Program Files\FlyFrogLLC\Happ\Happ.exe`, при необходимости передаёт документированную в интерфейсе команду `happ://connect`. Старую версию `F:\Happ` не использует. Существующая задача Happ с `--autostart` сохранена.

Затем проверяются включённый адаптер Happ Tunnel, маршрут IPv4 по умолчанию и доступность HTTPS Telegram/Codex. Только после успешной проверки запускаются приложение Codex и служба бота. Уже работающие процессы не дублируются. При ожидании сети повторяет проверку до 10 минут; планировщик допускает ещё три перезапуска. Состояние записывается в `data/startup-health.json`.

Текущая проверка VPN и реальный перезапуск службы через эту цепочку прошли. Настоящую перезагрузку с повторным входом в Windows ещё не выполняли. До входа в учётную запись Windows эта интерактивная цепочка не стартует. Автоматический вход в Windows не включали. HTTPS-проверка подтверждает доступность узлов, а не действительность авторизации Codex или наличие квоты. После ручного отключения VPN скрипт не включает его непрерывно; это порядок запуска, без сетевого kill switch. Для новой версии Codex предусмотрен поиск актуального пакета WindowsApps.

Исправление после реального обновления Codex: путь теперь определяется через регистрацию пакета текущего пользователя (`Get-AppxPackage OpenAI.Codex`), без необходимости перечислять защищённую папку WindowsApps. Устаревший путь в конфигурации служит запасным вариантом. Ошибка запуска приложения Codex больше не блокирует запуск бота после проверки VPN: бот сообщает о сбое и остаётся доступен для прямых команд. При каждом запуске службы отправляется «Привет! Я запустился и снова на связи». Заново запущенная цепочка успешно нашла установленный пакет 26.1016.8622.0; приветствие, пропущенная подборка и фото подтверждены Telegram API. Полный цикл выключения/включения с этим исправлением ещё не проверялся.

## Выключение из Telegram

| Команда | Действие |
|---|---|
| `/power` или «⏻ ПК» в панели | Кнопки управления ПК |
| `/shutdown` | Выключить компьютер через 60 секунд |
| `/reboot` | Перезагрузить компьютер через 60 секунд |
| `/shutdown 600`, `/reboot 600` | Своя задержка в секундах, от 30 до 86400 |
| `/cancelshutdown` | Отменить ожидающее выключение или перезагрузку |
| `/power_test` | Windows принимает тестовое выключение и перезагрузку с задержкой 10 минут; каждое немедленно отменяется |
| `/service_stop` | Остановить только бота до локального запуска |

Также распознаются точные фразы «выключи компьютер», «выключи пк», «перезагрузи компьютер», «перезагрузи пк», «отмени выключение», «отмени перезагрузку», в том числе после распознавания голосового. Голосовые команды зависят от правильности распознавания; для однозначного управления используй команды или кнопки.

Несохранённые данные могут потеряться: [Windows подразумевает принудительное закрытие приложений при положительном `/t`](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/shutdown). Команда не проходит через языковую модель или очередь Codex; доступны фиксированный локальный исполняемый файл и проверенные аргументы. Повторная доставка одного обновления не запускает действие снова. Ответ содержит результат Windows, а не обещание успеха при ошибке прав.

Реальный `/power_test` получен из Telegram: выключение, отмена, перезагрузка и отмена вернули код 0. Фактическое отключение питания и возврат после загрузки этим тестом не подтверждены. После выключения ПК бот недоступен. Удалённое включение компьютера не настроено.

## Панель, память и обратная связь

`/home` открывает одну закреплённую панель с новостями, почтой, сохранённым, напоминаниями, режимами, управлением ПК и паузой. Повторный вызов обновляет существующее сообщение. После изменения задач счётчики обновляются кнопкой «Обновить».

Под новыми ответами и фотографиями есть оценки 👍/👎, «Ещё такое», «Сохранить», «Напомнить», «Проще», «Озвучить», «В дело». В обзоре почты последняя кнопка готовит текст черновика ответа; письмо автоматически не отправляется. «В дело» предлагает проверку идеи и следующие шаги. «Напомнить» предлагает час, 19:00 или завтра 09:00 по Москве.

Ответом на конкретный пост можно написать «сохрани», «ещё», «попроще», «озвучь», «вечером напомни», «напомни через 20 минут». Контекст привязан к ID доставленного сообщения и сохраняется после перезапуска. Без ответа используется последний выбранный пост либо последний пост бота; при нескольких темах лучше отвечать на нужное сообщение.

`Запомни: ФАКТ` или `/remember ФАКТ` сохраняют явный факт локально в SQLite. `/memory` показывает настройки, до 30 последних фактов и число оценок; `/forget ID` удаляет конкретный факт, `/forget taste` сбрасывает оценки. Темы меняются через `/topics`. Уже подтверждённое пожелание «российские новости с фотографиями и без ссылок» сохранено с указанием исходных сообщений владельца. Факты и оценки переживают перезапуск и входят в контекст новых поручений; передаваемый контекст ограничен по длине. Это память данного помощника, не изменение глобальной памяти аккаунта Codex.

Режимы: `/mode normal`, `/mode focus` («Работаю»: полезные новости, почта, дела), `/mode leisure` («Отдыхаю»: больше лёгкого контента), `/mode quiet` («Тишина»: без автоматической ленты). Напоминания сохраняют расписание во всех режимах. Аварийная `/stop` приостанавливает и локальные напоминания; `/resume` возобновляет. Прямые запросы доступны и в режиме тишины.

«Озвучить» создаёт синтезированное голосовое Ogg/Opus локальным русским голосом Windows, до 1400 символов. Это синтезированная речь, не голос человека или голосовой модели. Входящие голосовые по-прежнему распознаются Whisper локально.

## Проверка

143 автоматических теста прошли после исправления запуска и доставки. Живые проверки: панель создана и закреплена, фото и голосовое доставлены, нажатие «Сохранить» обработано из Telegram. Подробности без секретов — `artifacts/experience-live-check.json` и `artifacts/delivery-repair-20261024.json`; кодовые результаты управления ПК сохраняются локально в `pc_power_test`. Unit-тесты блокируют реальные команды питания; отдельный живой тест выполнялся с немедленной отменой. Служебный XML heartbeat больше не показывается в Telegram; тихие результаты DONT_NOTIFY не отправляются.
